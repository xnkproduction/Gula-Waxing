# GULA Waxing Purwokerto

Landing page GULA Waxing Purwokerto (React + Vite + Tailwind). Live: https://xnkproduction.github.io/Gula-Waxing/

## Jalankan lokal
```
npm install
npm run dev
```

## Deploy
Push ke branch `main` → GitHub Actions otomatis build & deploy ke GitHub Pages.
Pastikan di repo: **Settings → Pages → Source: GitHub Actions**.

Base path relatif (`./`), jadi aman walau nama repo diganti.
